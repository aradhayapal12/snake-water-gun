# 🐍 🌊 🔫 Snake Water Gun Game

A clean, interactive web implementation of the classic Snake, Water, Gun game built using **Python** and **Streamlit**.

## 📌 Features
- 📊 Real-time score tracking using Streamlit `session_state`
- 🎨 Clean, color-coded win/loss/draw UI feedback
- 📱 Responsive layout that works on both mobile and desktop
- 🔄 One-click score reset functionality

---

## 🛠️ Game Rules
- 🐍 **Snake** drinks 🌊 **Water** *(Snake Wins)*
- 🌊 **Water** drowns 🔫 **Gun** *(Water Wins)*
- 🔫 **Gun** shoots 🐍 **Snake** *(Gun Wins)*
